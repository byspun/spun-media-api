### 3.4 Proxy architecture & animegg decision inputs
- **Proxying lives ONLY in the metadata (Worker) layer** — `providers/` has zero proxy logic.
  - `shouldProxyStream()` decides per-URL (`metadata/src/routes/stream.ts:21-37`) → proxies HLS `.m3u8` and "header-bound" mp4/dash; **plain mp4 with empty headers is passed through raw**.
  - `metadata/src/proxy.ts` performs the upstream fetch; **auto-sends `Referer`/`Origin` defaults = target's own origin** (line 59-61), forwards `Range`, follows `redirect: 'follow'`, allowlists `referer`/`origin` from token headers.
- **Why animegg bypasses proxy:** `providers/anime/animegg.ts:88` creates streams with `safeStream({url, quality, type})` passing **no headers** → falls into passthrough branch → raw `animegg.org` URL.
- **Why anime URL fails in browser:** animegg `302 → vidcache.net:8161/...` which enforces **Referer hand-off**. Verified live:
  - with `Referer: https://www.animegg.org/` → **200, 20 MB valid MP4**
  - vidcache direct (no Referer) → **500 `{"error":"Invalid request (bad hand off)"}`** (Range header alone doesn't satisfy it)
  - hover/click from browser on our domain → wrong Referer → same error.
- **Recommendation (not implemented — decision pending):** proxy animegg at metadata layer — one clause in `shouldProxyStream`; proxy auto-provides correct Referer; cookies not forwarded/needed; improves hotlink safety + one auth choke point.

### 3.5 `?k={key}` query-param auth (assessment only — does not exist yet)
- Confirmed: **no query-string auth anywhere today** — `authenticatePublic` reads only `X-User-Key`/`X-Admin-Key` headers.
- **Verdict: good idea, with guardrails:**
  1. Minimal value on `/v1/*` (headers work in curl/browser plugins), high value on `/v1/proxy/*` for `<video src>` playback.
  2. Key in a URL = bearer token → exclude `k` from access logs (current log line logs `path` only — keep it that way), rate-limit by key, reject if both header-key and `?k` supplied (`MULTIPLE_AUTH_METHODS` mirror).
  3. No anonymous `k`; never for root/admin routes.
- Effect on proxy: proxy.ts token auth (`?t=`) alone doesn't satisfy `authenticatePublic`'s `USER_KEY_REQUIRED` — proxy URLs are unplayable in a bare browser today (401 without headers; 403 when token expires, TTL **15 min** — `SUBTITLE_PROXY_TOKEN_TTL_SECONDS = 15 * 60`).
