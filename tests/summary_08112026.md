# Provider Stream Verification Summary — 39 Alive Providers

**Date:** 2026-11-08
**Branch context:** `dev`
**Scope:** Byte-level verification of streaming URLs from 39 providers sourced from three repos:
- Nuvio: `/root/provider-eval/all-in-one-nuvio/providers` (26 scrapers)
- Anivexa: `/root/provider-eval/anivexa-api` (10 providers, local worker.fetch)
- Varomine: `/root/provider-eval/varomine-Anime-Scraper-API` + `varomine-hanime.tv-api` (3 workers)

**Method:** Each provider invoked via its native code (`getStreams` / worker `fetch`) with probe TMDB/AniList IDs; returned URLs byte-verified:
- HLS: `#EXTM3U` in body
- DASH: `<MPD` in body
- MP4/MKV: `Range: bytes=0-2048` → 206
- Flixcloud: base64(XOR(key)) playlist decryption with `playlist_key`
- Cloudflare TLS-fingerprint blocks: curl subprocess fallback (403/401/503/0 → curl)
- Referer-gated CDNs: manual referer matrix (krussdomi←kaa.lt, animeonsen←www.animeonsen.xyz, nexabloom←megaplay.buzz, animegg←www.animegg.org, anipm/settlar curl-only)

**Harness:** `/root/provider-eval-scripts/test-39-streams.mjs` + shared `stream39-verify.mjs`
**Results store:** `/root/provider-eval-scripts/stream39-results.json` (39 rows, keyed by `source/id`)

## Key Technical Findings

1. **Flixcloud playlist encryption** — `master.m3u8` body = `base64(plaintext XOR repeating keyBytes)`. Key = extractor's `playlist_key` (base64, 32 bytes). XOR decrypt yields valid `#EXTM3U`.

2. **Cloudflare TLS-fingerprint blocks** — `media.settlar.io` (anipm), `playmogo.com` return 403 "Just a moment" to **any** Node/undici fetch regardless of headers. **curl subprocess passes**. Fixed via curl fallback in verifyUrl.

3. **Referer-gated CDNs** — 4 hosts require specific referers:
   - `hls.krussdomi.com` ← `https://kaa.lt/`
   - `cdn.animeonsen.xyz` ← `https://www.animeonsen.xyz/`
   - `fetch.nexabloom.top` ← `https://megaplay.buzz/`
   - `www.animegg.org` (mp4) ← `https://www.animegg.org/`

4. **Anikage proxy moved** — SPA chunk `c283.js` uses `PUBLIC_PROXY_URL` default `https://og.bakayaro.live` (old `prox.anikage.cc` 404s). Live server ids: `koto`, `kite` (`pahe` stale).

5. **Hanime worker** — Requires preamble.ts (`globalThis.process = undefined`) → vendor.js → index.ts load order with process restore. Landing shape `{sections:[{videos:[{slug}]}]}`. Stream URLs are long-token `hanime.tv/hls/{id}/{token}` (work direct AND via streamrelay).

6. **mkissa allanime clock.json** — One-hop API: `clock.json?id=<hex>` → `{links:[{link:"wixstatic/.../master.m3u8",hls:true}]}`.

7. **Nuvio config-gated** — gramcinema, showbox require settings tokens (not provided) → `no-stream`.
